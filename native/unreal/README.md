# Unreal challenger — deferred

Unreal Engine 5.8 remains a serious alternative, especially for high-end rendering, materials and procedural world tooling.

It is **not active yet**.

The owner has chosen to spend the next Codex budget qualifying Unity first. Do not create an Unreal project or duplicate Unity implementation work unless:

- Unity hits a documented blocker in agent automation, runtime matter rendering, meshing/collision, visual quality or procedural authoring; or
- the owner explicitly asks to run the Unreal challenger.

If activated, use the common comparison contract in:

- `docs/PC_ENGINE_BAKEOFF_PLAN.md`
- `native/shared/reference/`
- `native/shared/acceptance/`

and reproduce only the Unity evidence needed for the specific comparison rather than assuming a full equal-effort bakeoff.
