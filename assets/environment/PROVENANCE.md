# Ground detail artwork

`ground-paint.png` is original artwork generated with the built-in image generation tool on September 10, 2026 for Wildkin Frontier. It uses the new woodland Camp target as a style reference. The target itself was generated from the live game and Chris's supplied woodland reference.

Prompt: create a seamless neutral grayscale, top-down matte ground detail texture with broad, subtly varied polygonal worn-earth patches and restrained brushy chips, roughly twelve broad patches across its width. Gentle contrast, no objects, text, perspective, directional lighting, grain, reflections, shine or depth effects. Designed for light compositing over moss, tan and violet terrain colors.

The original generated output was `exec-dec00a8a-fbf9-49a6-99c2-2ed503c46e72.png`. The repository stores an unchanged copy. Runtime composites it once into each generated landscape color map, retaining local palettes, authored paths and shared render/physics heights. It is not a screenshot backdrop or a new collision surface.
