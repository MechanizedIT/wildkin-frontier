# First fitted diagnostic execution

The first fitted build stopped at its reach assertion before export: the rear-right chain exceeded reach by 0.02019m at the 0.045m body drop. No model was exported. A pure numerical sweep of the same 34 gait samples found 0.00633m excess at 0.065m drop and zero excess at 0.08m. The next build uses an 0.08m compression and tightens reach tolerance to 0.00001m, preserving stroke, lift and chain lengths. This is a pose fit correction, not geometry simplification.
