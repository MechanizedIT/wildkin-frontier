# Independent visual review — Lantern log manual R4

**Decision: HOLD for art and runtime admission; retain R4 as the stronger manual study.**

I compared all seven matched R3/R4 512px views, the principal R4 96px and 48px images, and the selected V2 reference. The matched camera fit makes the delta assessable. R4 improves on R3: warm wood, violet caps, and olive moss separate more clearly; the six-cap colony is still readable at 96px and 48px; and the irregular near rim gives the left end more life. The R3 stem/cap geometry is visibly retained, as intended.

R4 scores about **6.3/10** versus R3's 5.7. Colony/readability is 7.0, color hierarchy 7.0, broken-end improvement 6.3, log body/silhouette 5.0, and target likeness 5.8. It remains below the target threshold because every side and principal view still reads as a long, thin, deliberately extruded object. The upper and lower long planes are too continuous, the groove treatment is too subtle to create convincing broken wood mass, and the far raised tip reads as a blade. V2 instead depends on a fuller, tapering, irregular rootwood body with broad fracture planes and a compact broken end that supports the colony.

The builder evidence is accepted only for construction correctness: the receipt records exact preserved colony identity, 16 audited components / 1,390 triangles, 27 log ground-plane triangles totaling `.355010 m²`, and six passing local contacts. It does not prove target likeness, runtime readiness, collision, placement, harvest behavior, or global intersection safety.

## Method boundary

Do not repeat the same five-section elliptical body plus more rim offsets. If a later attempt is authorized, use a different construction method: block a short, fuller asymmetric wood mass from several broad cross-sectional volumes or a target-derived low-poly sculpt, then construct the shallow end recess within that mass. Preserve the current cap/stem centers only after reproving their actual attachment. A color-only pass or another set of narrow groove/rim adjustments will not close the persistent body defect.
