V3 replaces V2's rotational seven-sided ring walls with individually authored irregular clipped blocks. The whole-rock hull is the supported runtime descriptor. It deliberately closes recesses and the ledge underhang; it does not claim walk-under access. Optional chunk hulls in the manifest are study data only. No runtime compound schema was added.

The builder refuses existing output directories. To reproduce into new paths:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 4.5/blender.exe' --background --threads 2 --python tools/art/build-verdant-cliff-kit.py -- --output-dir <fresh-source-directory> --render-dir <fresh-render-directory>
```

Run one Blender process at a time. The scene uses Cycles CPU, two threads and eight samples; family views are 1280×640 and individual views are 640×640. The Blender sources are editable and each GLB embeds one opaque 256×256 palette material.

`final/export-verification.json` verifies exact sixteen source sRGB swatches in each embedded PNG, one opaque material, grounded Y-up GLB vertices and complete conservative hull coverage. `final/runtime-collider-verification.json` records validation through the actual game descriptor validator. The three `*-check.json` reports are structural prop checks, not visual admission.
