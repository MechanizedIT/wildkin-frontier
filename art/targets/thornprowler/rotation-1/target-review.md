# Thornprowler rotation 1 — independent construction-target review

## Decision: PASS as a bounded visual target

The target preserves the actual species read from the baked baseline: low dark-green crouched body, broad skull, cream jaw, swept tail, and seven ochre dorsal thorns. It directly addresses the observed defect: the baseline’s four paws are visually separated from the torso by razor-thin leg segments, while the target establishes four short, compact, volumetric load-bearing legs seated into those existing paws. At 48/96 px, the intended heavier ground silhouette should remain readable without making the animal tall or mammalian.

The target is adequate for a measured plan, not a template for hidden anatomy. The declared 1.47 m width and 1.26 m height are current actual-envelope constraints; 2.99 m length is explicitly inferred. A planner must use the real baked torso shell and paw attachment footprints to set each leg’s buried upper ring and visible clearance, then recompute the full envelope. It must preserve the actual four paws, skull/jaw, eyes, tail, seven thorn count, rusher behavior, source/home data, and collision contract.

For the dorsal line, retain seven separate ochre thorns but give each a buried base on the actual back shell. The target's illustrative views do not establish hidden depth, exact thorn bases, or exact limb sections. The later model gate must inspect all four legs, paw contacts, thorn attachments, and the low-profile silhouette in neutral views before a focused bake; a constructor edit alone cannot alter the admitted Frontier recipe.

This is visual reference approval only. It grants no runtime, behavior, habitat, or encounter admission.
