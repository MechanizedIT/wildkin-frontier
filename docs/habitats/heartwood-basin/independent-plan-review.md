# Heartwood Basin rotation 1 — independent planning review

## Decision: HOLD pending preproduction amendments

The packet has a sound bounded circuit intent, protects Camp/resources/wildlife, and retains the correct source-owner split. It is not ready to begin the structural pass under current owner direction because it lacks the required portrait-target selection stage and treats the claimed route length as though it were already defined evidence.

## Required amendments before source work

1. **Add the portrait-target gate.** After the fresh normal portrait baseline, author 2–4 feasible high-quality portrait targets from the actual camera/HUD, current kit, and protected route. Independently select and freeze one target with a short feasibility brief before the blockout matrix or structural pass. Generated target images are direction only; no target may imply a new system, global foliage change, or an unreviewed asset family.
2. **Define and measure the circuit.** Name the exact recognizable waypoints and order: Camp departure marker → starter-shelf threshold → western berry interaction space → Camp return marker. The stated 360–460 m is a planning range, not a proof. Fresh baseline evidence must record the actual ordinary-input trace/distance/time and its one or two gathering stops before it is reported as a route claim.
3. **Bound the coverage matrix as planning, not an extra implementation pass.** It must be a nonpublishing, reversible comparison with no canonical source commit or runtime behavior change. Record one fixed set of frames and the specified lane/clearance/count/conflict observations, select one configuration, then discard the other variants. It cannot be relabeled as a structural or visual pass and cannot consume repair budget invisibly.
4. **Align asset policy with current owner direction.** If the frozen blockout proves the current kit cannot fill one target-defining role, one small scoped asset may be created routinely within this visit without another owner approval. It still needs a separate reference/mesh review, editable source, mobile-cost proof, and cannot become an asset batch or delay the habitat's bounded three-pass loop.

With these amendments, the packet's structural pass plus up to two focused repairs is a coherent, protected visit. No fresh baseline, source change, or route success is established by this review.

## Recheck — pre-generation decision: PASS, target creation only

The amended packet now names the four player-recognizable waypoints, records the route range as an estimate until an ordinary-input trace exists, and requires 2–4 normal portrait targets followed by independent selection and a frozen brief before a coverage matrix or source work. It also correctly limits planning probes: a substantial native composition candidate counts as the structural pass or a repair. The new small-asset routine is bounded and reviewed rather than an asset-family expansion. Fresh matched baseline frames are present under `art/reviews/heartwood-basin/rotation-1/`.

This authorizes only the 2–4 target directions from those fresh frames and the protected current kit. It does not authorize geometry, source, a matrix candidate, or a route-success claim.
