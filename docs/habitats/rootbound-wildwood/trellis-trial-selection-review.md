# Rootbound Wildwood — TRELLIS2 trial selection review

## Recommendation: one coarse buttress-root / split-trunk anchor trial

Run the supervised TRELLIS2 experiment, if its independent resource audit clears it, on **one canopy-free Rootbound buttress-root and split lower-trunk anchor**. This is the highest-value coarse asset because it addresses Rootbound’s clearest missing structural constituent: a rooted near-camera mass that can frame a damp hollow without turning the open route into a wall.

Do **not** submit a whole leafy tree, the former broadleaf reference, a multi-panel sheet, or a root-and-stone scene. The prior full-tree attempts failed for separate reasons—decoded complexity, shallow canopy platters, disconnected/straight trunk methods, and target-likeness—not because a useful coarse rooted asset has been disproven. A canopy-free rooted trunk specifically changes the image-to-3D occupancy problem while remaining a useful constituent if it succeeds. Existing `asset_fallen_log`, `asset_mushroom_ring`, `asset_fen_stone`, low plants, and paddle/tall/spread canopies can supply the surrounding room language; none supplies this grounded root architecture.

## Trial reference contract

Use one clean opaque single-subject reference showing:

- one connected, faceted root base, 3–5 broad buttress roots, and a single warm split/truncated trunk;
- approximate raw role envelope: 4–5 m tall and 4–5.5 m lateral, with the entire root contact silhouette visible;
- a plain matte white or neutral background, weak/simple ground contact only, centered subject, no transparency halo;
- no foliage, leaf cards, separate stones, log, fungus, vines, thin branch tips, cast-ground clutter, text, or scene context.

The reference should communicate heavy, continuous lower volume and a modest asymmetric fork. It should not pretend to reconstruct the rejected hero broadleaf tree. A later Blender cleanup derivative may assess whether a restrained existing-canopy pairing is needed, but canopy production and runtime admission are outside this TRELLIS trial.

## Fair evaluation

1. Preserve the existing guarded staged runner and use its lowest supported experiment: 512, one step, one image, 30,000 requested export faces. Do not reduce memory/face safeguards or treat the requested export count as a decode cap.
2. A decoder result is useful only if decoded faces are at or below the existing 750k refusal threshold. Preserve the raw GLB, event/handoff receipts, hashes, and failure output either way.
3. If raw export exists, judge it as an **unadmitted coarse master**, not a finished tree: neutral front/rear/side/three-quarter plus 48/96 px renders must show a connected, grounded buttress silhouette with no detached fragments or paper-thin root sheets. Scale, contact, topology, and a compact lower-mass collider remain later gates.
4. Value the trial proportionally. A clean coherent coarse root master is a successful pipeline/constituent result even if it needs Blender cleanup and cannot yet meet the former broadleaf likeness threshold. A face-cap refusal or generic blob is a held experimental result, not a reason to bypass the guard.
5. Any later placement must be projected through the Rootbound destination/gallery portraits and checked against route, forage, wildlife, and collider exclusions. It must improve an edge frame while keeping the central pale lane and log/mushroom/stone composition readable.

## Evidence basis and limits

The selected Lantern Hollow target does not require a literal hero tree; it asks for a sheltered edge against a clear route. Rootbound’s dossier nonetheless identifies root architecture/canopy mass as its leading constituent gap. Earlier buttress v3 and Trials A/B are retained HOLD evidence: v3 was tree-readable but had paper roots/platter crowns; Trial A reached 7.4 but missed the bending trunk and deep canopy; Trial B failed connectedness. This experiment should begin from the simpler rooted-volume problem rather than reopen any exhausted candidate loop.
